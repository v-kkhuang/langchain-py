# 第一阶段 · 提示模板（第四步）学习笔记

> 阶段目标：学会 3 种模板、会用占位符、掌握 Few-Shot 和 partial，为 LCEL 管道打基础。

***

## 一、3 种模板选型速查

| 模板类                                | 适用场景                        | 创建方式                                |
| ---------------------------------- | --------------------------- | ----------------------------------- |
| `PromptTemplate`                   | **单轮**、纯文本提示词               | `from_template("...{var}...")`      |
| `ChatPromptTemplate`               | **聊天**、多角色（system/human/ai） | `from_messages([(role, tpl), ...])` |
| `FewShotChatMessagePromptTemplate` | **有格式要求**、需要给示例             | 套在 example\_prompt + examples 外面    |

记忆口诀：**单轮用 Prompt，聊天用 ChatPrompt，要学格式用 FewShot。**

***

## 二、核心用法详解

### 2.1 PromptTemplate（最基础）

```python
from langchain_core.prompts import PromptTemplate

# ① 建模板：用 {变量名} 当占位符
tpl = PromptTemplate.from_template("解释{topic}，受众是{audience}。")

# ② 查看变量
tpl.input_variables  # ['topic', 'audience']

# ③ 填充 → 字符串
tpl.format(topic="RAG", audience="小学生")

# ④ 直接拼 LCEL 管道（推荐！不用手动 format）
chain = tpl | llm
chain.invoke({"topic": "RAG", "audience": "小学生"})
```

### 2.2 ChatPromptTemplate（⭐重点，90% 场景用这个）

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

chat_prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{personality}的{job}。"),          # 固定人设
    MessagesPlaceholder(variable_name="chat_history"),      # 🎯 历史对话占位符
    ("human", "{question}"),                                # 用户最新问题
])
```

**MessagesPlaceholder** 是关键：

- 变量名随意（通常叫 `chat_history` 或 `history`）
- 传值时必须是 `list[BaseMessage]`，即 `[HumanMessage(...), AIMessage(...), ...]`
- 没有历史就传空列表 `[]`，不要不传

### 2.3 Few-Shot（少样本）

```python
examples = [
    {"input": "太好了！",   "output": "positive"},
    {"input": "太差劲了。", "output": "negative"},
]
example_tpl = ChatPromptTemplate.from_messages([
    ("human", "{input}"),
    ("ai", "{output}"),
])
few_shot = FewShotChatMessagePromptTemplate(
    example_prompt=example_tpl,
    examples=examples,
)
final_prompt = ChatPromptTemplate.from_messages([
    ("system", "严格按示例分类，不要解释。"),
    few_shot,                                              # 示例会插在这里
    ("human", "{input}"),
])
```

**什么时候用 Few-Shot？**

- ✅ 需要固定输出格式（JSON、特殊分隔符）
- ✅ 需要模仿特定风格
- ✅ 分类/抽取等规则不直观的任务
- ❌ 自由聊天/大段创作（反而限制模型）

## 三、进阶技巧

### 3.1 `.partial()` 部分绑定

**问题**：一个模板 5 个变量，其中 3 个在程序启动时就确定了，剩下 2 个每次调用才给。
每次都传 5 个太啰嗦。

```python
base = PromptTemplate.from_template(
    "你是{role}，用{style}写一段关于{topic}的{length}内容。"
)
# 先绑死 2 个 → 剩 topic, length
my_tpl = base.partial(role="编程博主", style="幽默")
my_tpl.input_variables  # ['topic', 'length']  ✂️ 只剩 2 个
```

### 3.2 模板也是 Runnable！

所有 PromptTemplate 都实现了 Runnable 接口，所以：

- `prompt.invoke({"a": 1})`  → 返回 PromptValue
- `prompt | llm`             → 合法的 LCEL 管道（返回 AIMessage）
- `prompt | llm | parser`    → 加上 OutputParser（第五步内容）
- `.batch()` / `.stream()` / `.ainvoke()` 全支持

**这就是为什么第五步我们能写出** **`prompt | llm | parser`** **这种优雅管道。**

## 四、常见坑 & 避坑

| 坑                         | 现象                        | 解决                           |
| ------------------------- | ------------------------- | ---------------------------- |
| 变量名拼错                     | `KeyError: 'topc'` 或输入没替换 | 看 `input_variables` 核对拼写     |
| 模板字符串少了 `{}`              | 变量原样输出，根本没替换              | `topic` vs `{topic}`，后者才对    |
| MessagesPlaceholder 传了字符串 | 运行时报类型错                   | 必须传 `list[Message]`，不是 `str` |
| <br />                    | <br />                    | <br />                       |
| Few-Shot 示例太少             | 格式不稳定，偶尔输出解释              | 加到 3\~5 个多样示例                |
| 聊天模板里混用 PromptTemplate    | 类型不兼容报错                   | 聊天场景统一用 ChatPromptTemplate   |
