# 第一阶段 · 模型调用（第三步）学习笔记

> 阶段目标：会初始化模型、掌握 4 种调用方式、理解 temperature 等参数、会写多轮对话消息数组。

---

## 一、4 种核心调用方式（Runnable 接口）

LangChain 中所有组件都实现了 **Runnable 协议**，调用方式统一：

| 方式 | 方法 | 适用场景 | 返回类型 |
|------|------|---------|---------|
| 同步单次 | `invoke(messages)` | 最简单，一次请求一个答案 | `AIMessage` 对象 |
| 同步流式 | `stream(messages)` | 聊天打字机效果，体验更好 | `AIMessageChunk` 迭代器 |
| 同步批量 | `batch([m1, m2, m3])` | 多个独立问题并行跑 | `list[AIMessage]` |
| 异步单次 | `ainvoke(messages)` | FastAPI / Web 服务，不阻塞主线程 | `AIMessage`（协程） |
| 异步流式 | `astream(messages)` | 异步 Web 场景 | 异步迭代器 |
| 异步批量 | `abatch([...])` | 异步批量 | 协程返回 list |

**关键记忆点**：所有方式的输入输出结构一致，只是「并发方式」和「返回节奏」不同。
后续学 LCEL 管道 `prompt | llm | parser` 时，这 6 个方法直接复用，不用重新学。

## 二、模型初始化的 3 种方式

### 方式 A：Provider 专属包（推荐，类型最完整）
```python
from langchain_deepseek import ChatDeepSeek

llm = ChatDeepSeek(model="deepseek-chat", temperature=0)
```
优点：参数自动补全好，类型提示准。
需要 `pip install langchain-deepseek`（你的项目里已经装了）。

### 方式 B：通用工厂 init_chat_model（LangChain 1.x 新特性）
```python
from langchain.chat_models import init_chat_model

llm = init_chat_model("deepseek:deepseek-chat", temperature=0)
```
优点：一行切换 provider，比如改成 `"openai:gpt-4o-mini"` 或 `"tongyi:qwen-plus"`。

### 方式 C：ChatOpenAI 兼容模式（适合国产模型 / 自建 API）
```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="qwen-plus",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    api_key=os.getenv("DASHSCOPE_API_KEY"),
)
```
**绝大多数国产模型都兼容 OpenAI 接口**，用这种方式即可接入。

## 三、关键参数理解

| 参数 | 范围 | 作用 | 推荐学习阶段默认值 |
|------|------|------|------------------|
| `temperature` | 0 ~ 2 | 控制随机性，0=每次一致，值越高越有创造力 | **0**（调试方便） |
| `max_tokens` | 正整数 | 最多生成多少个 token，超过会截断 | 500（够用不浪费） |
| `model` | 字符串 | 选具体模型名 | deepseek-chat / qwen-plus / gpt-4o-mini |

### temperature 选型速查
```
0    → 分类、抽取、SQL 生成、格式化（要稳定的场景）
0.5  → 代码助手、一般问答
0.7  → 默认通用值
1.0+ → 创意写作、起名、头脑风暴
1.5+ → 容易胡言乱语，少用
```

## 四、消息格式（3 种 role）

**这是多轮对话的核心，后面学 Memory、LangGraph 全靠这个格式**：

```python
messages = [
    {"role": "system", "content": "你是一个 XX 助手，必须 YY"},  # 人设/规则，只放 1 条在最前
    {"role": "human", "content": "用户说的话 1"},  # 用户输入
    {"role": "ai", "content": "模型的回复 1"},  # 模型输出
    {"role": "human", "content": "用户说的话 2"},
    {"role": "ai", "content": "模型的回复 2"},
    # ... 继续追加
]
```

**易错点**：
- ❌ 不要丢掉上一轮历史直接发新问题，模型会「失忆」
- ❌ 不要出现 role 拼写错误（huamn / assitant 之类）
- ✅ 顺序严格按对话时间来，`system` 只在最前面
